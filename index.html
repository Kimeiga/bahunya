Bahunya

A classless CSS framework for semantic HTML.

Install

Paste this into your document's <head>:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/kimeiga/bahunya/dist/bahunya.min.css">

Themes

Bahunya is dark by default. Add data-theme="light" to <html> for the bundled light theme.

<html data-theme="light">

Navigation

A direct child <nav> becomes the site navbar. Navigation elsewhere in the document keeps normal document flow.

<nav aria-label="Primary">
  <a href="/">Home</a>
  <a href="/about">About</a>
</nav>

Nested lists work as dropdowns with pointer hover or keyboard focus.

Goal

Bahunya styles semantic HTML directly so small sites and web apps can start with readable markup and a useful visual baseline without learning framework-specific class names.
